# ZA-TECH

Site institucional de um laboratório de informática em Fortaleza: reparo e manutenção de notebooks, desktops, GPU, placa-mãe e fonte.

Desenvolvido com HTML5, CSS3 (Grid e Flexbox) e JavaScript. Hero com fotos reais, texto em máquina de escrever, abas de serviço, botões flutuantes e contato direto no WhatsApp. Layout responsivo para celular e desktop.

Este repositório é a única publicação deste projeto.
