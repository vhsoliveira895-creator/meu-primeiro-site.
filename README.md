# meu-primeiro-site.
CellTech: Landing page moderna de e-commerce desenvolvida com HTML5, CSS3 (Grid/Flexbox) e JavaScript. Apresenta background de vídeo dinâmico com barra de progresso em tempo real, design responsivo (Mobile First), efeitos de Glassmorphism e tratamento de erros de mídia. Focada em performance e UI/UX limpa para dispositivos móveis.
