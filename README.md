# ZA-TECH

Site institucional de um laboratorio de informatica em Fortaleza: reparo e manutencao de notebooks, desktops, GPU, placa-mae e fonte.

Desenvolvido com HTML5, CSS3 (Grid e Flexbox) e JavaScript. Hero com fotos reais, texto em maquina de escrever, abas de servico, botoes flutuantes e contato direto no WhatsApp. Layout responsivo para celular e desktop.

Este repositorio e a unica publicacao deste projeto.
